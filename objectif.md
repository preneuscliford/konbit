# Vision produit de Konbit (V1)

## Contexte

Konbit est un réseau social moderne inspiré de X et Reddit, conçu pour la communauté haïtienne puis extensible à d'autres communautés.

L'objectif n'est pas de concurrencer Facebook en reproduisant toutes ses fonctionnalités, mais de proposer une expérience plus simple, plus rapide et davantage centrée sur les échanges utiles.

Le mot "Konbit" symbolise la coopération, l'entraide et l'action collective. Cette philosophie doit être présente dans toute l'application sans rendre l'expérience complexe.

---

# Philosophie

Construire une application que l'utilisateur comprend en moins de 10 secondes.

Chaque fonctionnalité doit répondre à une question simple :

> Est-ce que cette fonctionnalité aide les membres de la communauté à communiquer, découvrir des informations ou s'entraider ?

Si la réponse est non, elle ne doit pas être intégrée à la V1.

---

# Expérience utilisateur

L'application doit être fluide, moderne et minimaliste.

Nous privilégions :

- une navigation simple ;
- un design propre ;
- des animations discrètes ;
- un chargement rapide ;
- très peu d'écrans.

Nous voulons éviter toute impression d'application surchargée.

---

# Navigation

La navigation principale comporte uniquement cinq onglets :

1. Accueil
2. Découvrir
3. Créer
4. Messages
5. Profil

Aucun onglet supplémentaire dans la V1.

---

# Le fil d'actualité

Le fil est le cœur de Konbit.

Il mélange naturellement plusieurs types de contenus :

- publications classiques ;
- photos ;
- vidéos ;
- annonces ;
- événements ;
- demandes d'aide.

Toutes les publications utilisent le même composant afin de conserver une expérience cohérente.

---

# Les publications

Lorsqu'un utilisateur crée un contenu, il peut choisir son type :

- Publication
- Demande d'aide
- Annonce
- Événement

Chaque type reste visuellement proche afin de ne pas compliquer l'interface.

---

# Communauté

Les utilisateurs peuvent :

- aimer une publication ;
- commenter ;
- partager ;
- enregistrer ;
- suivre d'autres membres.

Ces interactions doivent rester simples et familières.

---

# Découverte

L'onglet Découvrir permet de retrouver :

- tendances ;
- communautés ;
- hashtags ;
- personnes ;
- sujets populaires.

Nous voulons favoriser les conversations locales et communautaires.

---

# Messages

Messagerie privée moderne.

Fonctionnalités minimales :

- conversations individuelles ;
- envoi de photos ;
- notifications.

Les groupes pourront être ajoutés plus tard.

---

# Profil

Chaque utilisateur possède :

- photo ;
- biographie ;
- publications ;
- nombre d'abonnés ;
- nombre d'abonnements.

Le profil reste volontairement simple.

---

# Ce que nous ne voulons PAS dans la V1

- Marketplace complète
- Wallet
- Paiements
- Reels
- Stories
- Jeux
- Fonctionnalités complexes
- Menus surchargés

Toutes ces idées pourront être ajoutées après validation du produit.

---

# Design

Le design doit être premium.

Inspirations :

- X
- Reddit
- Threads
- Discord

Éviter toute copie visuelle.

Privilégier :

- beaucoup d'espace ;
- typographie lisible ;
- animations fluides ;
- palette moderne ;
- identité propre à Konbit.

---

# Objectif

Créer un réseau social communautaire moderne qui donne envie d'être ouvert chaque jour, tout en favorisant naturellement les échanges utiles et l'entraide.

La simplicité doit toujours primer sur le nombre de fonctionnalités.
