# Refonte complète de Konbit – Nouvelle vision produit

Nous allons repartir sur de nouvelles bases.

Le projet actuel a été développé avec une logique proche d'un réseau social classique (posts, commentaires, likes, etc.). Cette base était utile pour valider des composants techniques, mais elle ne correspond plus à notre vision.

Nous ne voulons pas créer un clone de X, Reddit ou Facebook.

Nous voulons créer **Konbit**, un réseau social avec sa propre identité.

## Notre vision

Le mot **Konbit** vient d'Haïti et représente l'entraide, la coopération et l'action collective.

Cependant, l'application n'est pas destinée uniquement à Haïti.

Notre ambition est de créer une plateforme mondiale où n'importe quelle communauté peut s'organiser, lancer des projets, demander de l'aide ou rassembler des personnes autour d'un objectif commun.

L'inspiration est haïtienne, mais le produit est universel.

## Le cœur de l'application

La fonctionnalité principale n'est plus :

- créer un post ;
- publier une photo ;
- partager un statut.

Le cœur de l'application devient :

**Créer une Konbit.**

Une Konbit représente une initiative.

Elle peut être :

- une demande d'aide ;
- un projet ;
- une idée ;
- un événement ;
- une action locale ;
- une collecte ;
- une mission ;
- ou simplement une discussion qui vise à rassembler des personnes autour d'un objectif.

Toute l'application doit être construite autour de ce concept.

## Nouvelle expérience utilisateur

Nous devons abandonner la logique "Créer un post".

À la place, l'utilisateur verra un bouton principal :

**Créer une Konbit**

La création d'une Konbit doit être simple.

Exemple de parcours :

- Titre
- Description
- Catégorie
- Localisation (optionnelle)
- Date (optionnelle)
- Nombre de participants recherché (optionnel)
- Images ou vidéos (optionnelles)

L'objectif est de permettre de lancer une initiative en moins d'une minute.

## Comment les utilisateurs interagissent

Une fois publiée, une Konbit devient un espace vivant.

Les utilisateurs peuvent :

- rejoindre une Konbit ;
- proposer leur aide ;
- laisser un commentaire ;
- partager des idées ;
- suivre l'évolution ;
- inviter d'autres personnes ;
- enregistrer la Konbit ;
- partager la Konbit.

Chaque Konbit possède un état :

- Nouvelle
- En cours
- Terminée

Le créateur peut publier des mises à jour pour montrer l'avancement.

## Le fil d'actualité

Le fil d'actualité n'affiche plus uniquement des posts.

Il affiche principalement des Konbits.

Chaque carte doit mettre en avant :

- le besoin ou l'objectif ;
- le nombre de participants ;
- l'état d'avancement ;
- les dernières activités.

## Identité visuelle

Le design actuel doit être repensé.

Nous voulons une identité propre.

Inspirations :

- simplicité de Threads ;
- qualité de l'interface d'Apple ;
- rapidité de X ;
- richesse des échanges de Reddit.

Mais sans copier aucune de ces plateformes.

Le design doit être minimaliste, moderne et chaleureux.

Le bouton "Créer une Konbit" doit devenir l'élément central de l'application.

## Philosophie

Chaque nouvelle fonctionnalité devra répondre à une seule question :

> Est-ce qu'elle aide les utilisateurs à créer, rejoindre ou faire avancer une Konbit ?

Si la réponse est non, elle ne doit probablement pas faire partie de la V1.

Nous préférons une application simple avec une identité forte plutôt qu'une application qui copie toutes les fonctionnalités des réseaux sociaux existants.

L'objectif est de construire un produit immédiatement reconnaissable, où les utilisateurs ne disent pas "j'ai publié un post", mais "j'ai créé une Konbit".

# Évolution de Konbit

Nous souhaitons recentrer complètement l'expérience utilisateur autour de la **Konbit**.

Une Konbit représente une initiative qui rassemble des personnes autour d'un objectif commun.

L'ensemble de l'application doit désormais être pensé autour de cette idée.

## Création d'une Konbit

Le point d'entrée principal de l'application devient **Créer une Konbit**.

La création doit être rapide (moins de 30 secondes).

Informations proposées :

- Titre
- Description
- Catégorie
- Localisation (optionnelle)
- Date (optionnelle)
- Nombre de participants recherché (optionnel)
- Photos (optionnelles)

L'expérience doit rester extrêmement simple.

## Participation

Rejoindre une Konbit doit être aussi simple qu'aimer une publication.

L'utilisateur clique simplement sur **Je participe** ou **Je peux aider**.

Le créateur peut ajouter quelques conditions facultatives :

- nombre maximal de participants ;
- compétences recommandées ;
- participation locale uniquement.

Aucun formulaire complexe ne doit être demandé.

## Vie d'une Konbit

Une Konbit est un espace vivant.

Une fois qu'un utilisateur participe, il peut :

- voir les autres participants ;
- quitter la Konbit ;
- recevoir les mises à jour ;
- participer aux discussions.

## Suivi de la progression

Le créateur doit pouvoir publier facilement des mises à jour.

Exemples :

- La Konbit commence.
- Nous recherchons encore des participants.
- L'objectif est atteint.
- La Konbit est terminée.

Chaque Konbit possède également un statut visuel :

- Nouvelle
- En préparation
- En cours
- Terminée

L'objectif est que les participants puissent comprendre instantanément où en est l'initiative.

## Discussion

Chaque Konbit possède son propre espace de discussion réservé aux participants.

Les membres peuvent :

- envoyer des messages ;
- partager des photos ;
- partager des fichiers ;
- organiser les prochaines étapes ;
- échanger librement.

L'objectif est que toute l'organisation d'une Konbit puisse se faire directement dans l'application.

## Design

Le design doit évoluer pour mettre en valeur la création et la participation aux Konbits.

Le bouton **Créer une Konbit** doit devenir l'action principale de l'application.

L'interface doit être moderne, minimaliste, chaleureuse et très intuitive.

## Liberté de proposition

N'hésite pas à proposer une meilleure architecture, une meilleure navigation ou une meilleure expérience utilisateur si cela permet de renforcer cette vision.

Notre objectif est de construire une expérience unique où tout tourne autour des Konbits et de leur évolution.
